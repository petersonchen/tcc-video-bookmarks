# Privacy

TCC Video Bookmarks is designed to operate locally in the browser.

- Bookmark data is stored with `chrome.storage.local`.
- The extension does not require an account.
- The extension does not send bookmark data to a developer-operated server.
- Website access is limited to `https://live.tcc.gov.tw/*`.
- The extension reads the current HTML5 video time and page/video identity only to save and restore bookmarks.

If future versions add network services, this policy should be updated before release.
